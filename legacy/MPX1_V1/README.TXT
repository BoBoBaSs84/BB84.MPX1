- Supports Lexicon's MPX 1 Multi Effects processor
- For use with IBM PC's or compatible hardware
- For use with Windows V3.1 or Windows 95 operating systems
- You must have MIDI card and cables.  You can use a Sound Blaster card or
  MPU401 card and appropriate Windows driver installed.

This is what I call "Freeware" (that means, as is).  It is being provided as
is, to assist any owners of the MPX 1 with a way of editing and archiving
effects.  It's not intended to be a commercial editor, I'll leave that to the
professionals.  This was part of a testing tool used to help in development and
testing of the MPX 1 and I am just passing on the remains... <grin>

Included files:   - MPX1EDIT.EXE Windows Program   03/30/98 9:00PM
                  - MPX1HLP. HLP Help file         03/30/98 9:00PM

Simply run MPX1_V1.EXE to extract the two files.

Make a new directory ie. C:\MPX1.  Copy MPXEDIT.EXE and MPX1HLP.HLP files to
the created directory.  Create a new program item or program group if using
Windows V3.1, shortcut or folder if using Windows 95.  See Windows manuals for
setting these up.  Connect MIDI in/out from your PC to your MPX 1 and click on
MPX 1 icon to start editor.  Read through the help file from the editors main
menu.  Play around with it...  Feel free to drop me a line with your comments,
I`d like to know what you think.
